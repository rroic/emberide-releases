# EmberIDE downloads

Signed builds of EmberIDE and the update feed (`appcast.xml`) used by its built-in updater.

**Install**: download the latest `EmberIDE-x.y.z.zip` from [Releases](https://github.com/rroic/emberide-releases/releases), unzip it and move
EmberIDE.app to Applications. The app is not notarized by Apple, so macOS blocks the first launch: open
**System Settings ▸ Privacy & Security**, scroll down and click **Open Anyway** (on macOS 14 and earlier you can also right-click the app ▸ Open).
After that EmberIDE updates itself (EmberIDE ▸ Check for Updates…).
